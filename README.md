# 📊 Data Analyst Portfolio

Welcome to my **Data Analyst Portfolio** 👋

This repository presents a collection of data analysis projects focused on **data cleaning**, **exploratory data analysis**, **visualization**, and **insight generation**.

Each project is structured as a complete case study to demonstrate my ability to analyze data, identify patterns, and communicate findings clearly.

The goal of this portfolio is to showcase practical data analysis skills using real-world datasets and professional documentation.

---

## 📁 About This Portfolio

Each project in this repository includes:

- 📂 A dedicated project folder
- 📝 A clear project README
- 🗃️ The dataset or dataset reference
- 📓 Jupyter Notebook analysis
- 📊 Visualizations and charts
- 📄 A PDF report attached inside the project folder
- 🔗 The original GitHub repository link below the project description

The PDF report for each project is included in the corresponding project folder, usually inside the `reports/` directory.
