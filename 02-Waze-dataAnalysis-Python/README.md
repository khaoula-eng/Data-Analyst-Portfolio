# 🚗 Waze User Retention Analysis | Python

Exploratory analysis of Waze user activity data to understand driving behavior, app engagement and the factors behind user churn.

## 🎯 Objectives
- Assess the structure and quality of the dataset
- Explore engagement metrics: sessions, drives, activity days, kilometers driven
- Compare **retained** and **churned** users to identify retention patterns

## 🗃️ Dataset
User-level Waze data including sessions, drives, days since onboarding, navigations to favorite places, kilometers driven, driving duration, activity days, device type and retention status (`label`).

## 🛠️ Tools
Python · Pandas · NumPy · Jupyter Notebook

## 📂 Files
- `Waze Data Analysis.ipynb` – analysis notebook
- `waze_dataset.csv` – dataset
