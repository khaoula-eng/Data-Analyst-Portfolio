# E-Commerce Store Analysis Using Power BI

Interactive Power BI dashboard analyzing the sales of an Indian e-commerce store: revenue, profit, quantity and performance by category, payment mode, region and month.

<img width="1224" height="693" alt="image" src="https://github.com/user-attachments/assets/5836f71a-efb5-437b-9b29-843a9c02b48a" />

## Features
- KPIs: Amount (438K), Profit (37K), Quantity (5,615), AOV
- Visuals: category, payment mode, sub-category profit, top customers, states, cities, monthly profit
- Filters: Quarter and State

## Key Insights
- Clothing makes up 63% of quantity sold.
- Cash on Delivery is the top payment method (44%).
- Printers are the most profitable sub-category (8.6K).
- Maharashtra leads sales (102K); Indore is the top city.
- Losses in May, June, July and December.

## Tools
Power BI · Power Query · DAX
